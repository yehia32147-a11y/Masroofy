# Masroofy

A free, bilingual (Arabic/English) business assistant prototype.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Safari, or Firefox.
3. Choose Arabic or English from the top-right language button.
4. Add orders and products. Your data is saved in that browser on that device.

## Features
- Sales and estimated-profit dashboard
- Order tracking with pending/completed status
- Product inventory
- Customer reply templates in Arabic and English
- JSON backup export
- Responsive layout for phones and computers

## Important limitations
- This is a local prototype. Data is stored in browser localStorage, not synced between devices.
- The reply helper uses templates. It is NOT connected to an AI model.
- No account system, online database, payment processing, or multi-user access is included.
- Do not enter sensitive customer or payment information.
- For a public launch, add secure authentication, a real database, privacy terms, and server-side validation first.

## Publish free
You can host this static prototype with a free static-site hosting tier (for example, GitHub Pages). A parent/guardian may need to help create or manage accounts because of age requirements. The exact free-tier terms can change.
